### 🎓 CGP Calculator System (Java)

A Java-based application designed to calculate CGPA (Cumulative Grade Point Average) based on course grades and credit hours. This project demonstrates the application of Object-Oriented Programming concepts in an academic grading system.

#### 🚀 Features

* Calculate CGPA from multiple courses
* Input and manage course grades and credit hours
* Encapsulated logic for grade computation
* Clear and modular class structure
* Simple and user-friendly implementation

#### 🛠️ Tech Stack

* **Language:** Java
* **Paradigm:** Object-Oriented Programming (OOP)

#### 📂 Project Structure

* `CGP/` – Core logic for CGPA calculation
* `Course/Class files` – Represents course data
* `Main.java` – Entry point for execution

#### 🎯 Purpose

This project was developed to:

* Practice Java programming and OOP concepts
* Understand how to model academic systems
* Implement real-world calculations in code
